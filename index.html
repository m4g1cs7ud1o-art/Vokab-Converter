Vokabel-JSON erstellen

Bilder oder PDFs automatisch auslesen lassen und erkannte Englisch-Deutsch-Vokabeln in eine JSON-Datei umwandeln. Die Dateien bleiben lokal auf deinem Gerät. Zur Texterkennung muss eine Internetverbindung bestehen, damit die Browser-Bibliotheken geladen werden können.

1. Vorlagen auswählen

Falls dein Browser die PDF-Vorschau nicht unterstützt, öffne das PDF in einem neuen Tab.

2. Liste benennen

3. Erkannte Vokabelpaare

Die erkannten Paare werden automatisch eingetragen. Prüfe sie kurz auf OCR-Fehler; bei Bedarf kannst du den Text direkt korrigieren. Einzelne Vokabeln musst du nicht abtippen.
